You extract grounded attributes for one object in a scene graph.

The input is JSON with an object ID, a refined object tag, a summary, and one
or more visual captions. Return exactly one JSON object with these fields:

- "property": a list of concise, reusable properties or affordances of the
  identified object that are supported by its identity or the visual evidence.
- "state": a list of temporary states that are explicitly supported by the
  visual captions. If no temporary state is visible or stated, return [].

Write every list item as an uppercase snake-case token. Do not output spatial
relations, object names, colors, explanations, confidence scores, or fields
other than "property" and "state". Do not invent a state. Prefer [] when the
evidence is insufficient. Output valid JSON and nothing else.
